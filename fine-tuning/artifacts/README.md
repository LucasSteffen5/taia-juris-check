# Checkpoints versionados

`v1-reference/` contém a referência histórica necessária para inicializar parte da campanha v2. `v2-selected/` é a exportação congelada pela validação local, pronta para inferência offline e para publicação posterior no Hugging Face. Cada diretório inclui `model.safetensors`, tokenizer, configuração, procedência e relatório; o v2 inclui também os parâmetros efetivos, manifestos, histórico, avaliação oficial da amostra de desenvolvimento e `REPRODUCE.md`.

Os dois arquivos `model.safetensors` são objetos Git LFS. Após clonar, execute `git lfs pull` e confira que os hashes SHA-256 correspondem aos registrados em `provenance.json`. O wrapper `fine-tuning/run.ps1` ou `fine-tuning/run.sh` usa o v1 daqui como referência, sem depender da pasta local `runs/`. Os dados originais já versionados no repositório e o checkpoint original em `models/ner_legal_large` completam as entradas da campanha.

O v2 selecionado tem SHA-256 `52b24416c23a645db9aa49e83cf59e14aa8b225ae396f01d48415d50ae67945c`. Na validação local marcou 0,675424; no teste local, 0,669523. Nos 16 documentos da amostra oficial reservados, o score do v1 foi 1,082703 e o do v2 foi 1,082643. Essa amostra não é o conjunto final cego da competição e não foi usada para escolher outro checkpoint. A imagem Docker principal agora empacota o v2 como padrão. Consulte o README da raiz para executar os 26 documentos, e [PUBLICAR_HUGGING_FACE.md](../PUBLICAR_HUGGING_FACE.md) para publicar a exportação.

O pacote v2 publica pesos de inferência, configurações, hashes, métricas e histórico, sem textos de treino, bancos SQLite, caches, credenciais ou estados do otimizador. Estes últimos existiram nos checkpoints completos durante o treino e foram testados para retomada FP16, mas foram compactados após a seleção. Seus hashes e essa limitação constam de `v2-selected/checkpoint_archive.json` e `v2-selected/REPRODUCE.md`. A reexecução da campanha a partir dos dados e das referências versionadas é suportada; igualdade bit a bit entre ambientes CUDA não é garantida.
